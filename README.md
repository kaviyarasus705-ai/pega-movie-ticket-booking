# pega-movie-ticket-booking
Movie Ticket Booking Management Application developed using Pega App Studio, featuring ticket requests, seat availability, booking approval, cost calculation, seat allocation, and booking confirmation workflows.

# Movie Ticket Booking Management Application

This project is developed using Pega Platform.

## Case Type
Movie Ticket Request

## Stages
1. Request
2. Availability
3. Approval
4. Booking Execution

## Main Features
- Submit movie ticket request
- Check show availability
- Calculate booking cost
- Confirm booking
- Maintain Movie and Show data
- Process ticket booking
- Send booking confirmation
- Configure SLA
- Route booking based on show type

## Platform
Pega App Studio / Pega Infinity
